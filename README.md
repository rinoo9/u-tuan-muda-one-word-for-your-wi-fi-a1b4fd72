# One Word for Your Wi-Fi — "Houdini"

A one-word entry for the make.fun bounty "One Word for Your Wi-Fi". The program `main.py` writes the single word "Houdini" to `/output/entry.txt`, with nothing else: no newline, no extra words.

Why "Houdini"? The signal does not just fade — it escapes, mid-call, mid-video, mid-download, then reappears as if nothing happened, and no one can say how it got out. The joke needs no explanation, and as a network name it is one people would smile at and remember. (Round 1 entry was "Peekaboo".)

Run it with `python3 main.py` (Python 3.13).
